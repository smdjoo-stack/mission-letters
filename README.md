# 선교편지

선교사가 후원자와 후원교회에 보낼 편지를 만들고 공유하는 웹앱입니다.
서버도, 데이터베이스도, 비용도 필요하지 않습니다.

- 편지 본문은 **비밀번호로 암호화**되어 저장됩니다. 저장소가 공개여도 내용이 노출되지 않습니다.
- 사진은 **구글 드라이브 공유 링크**를 붙여넣어 넣습니다.
- 후원자는 **링크 하나**로 읽고, **A4 PDF**로 저장할 수 있습니다.
- 편지 발행에 **git 명령이 필요 없습니다.** 앱의 "발행" 버튼이 대신 합니다.

**처음이시라면** [선교편지가 가는 길](guide.html) 을 먼저 읽어보세요 — 이 구조가 왜 이런지 그림으로 설명합니다.
(웹에서 보기: `https://smdjoo-stack.github.io/mission-letters/guide.html`)

명세는 [선교편지제작_PRD_v2.md](선교편지제작_PRD_v2.md) 를 보세요.

## 처음 한 번만 하는 준비 (약 10분)

### 1. GitHub 저장소 만들기

1. [github.com/new](https://github.com/new) 에서 저장소를 만듭니다. 이름은 예를 들어 `letters`.
2. **Public** 으로 두어도 됩니다. 편지는 암호화되어 저장됩니다.
   (GitHub Pro 이상이라면 Private 으로 두고 Pages 만 공개하는 편이 더 안전합니다.)

### 2. 이 폴더의 파일을 저장소에 올리기

`index.html`, `assets/`, `letters/`, `.nojekyll` 을 저장소 최상위에 올립니다.
드래그 앤 드롭으로 업로드해도 됩니다.

### 3. GitHub Pages 켜기

저장소 → **Settings → Pages** → Source 를 **Deploy from a branch**,
Branch 를 **main / (root)** 로 두고 저장합니다.
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소가 열립니다.

### 4. 토큰 발급하고 앱에 입력하기

[fine-grained 토큰 발급 화면](https://github.com/settings/personal-access-tokens/new) 에서:

| 항목 | 값 |
|---|---|
| Token name | 아무 이름 (예: `선교편지`) |
| Repository access | **Only select repositories** → 위에서 만든 저장소 하나만 |
| Permissions → Repository permissions → **Contents** | **Read and write** |

만들어진 `github_pat_...` 값을 앱의 **설정** 화면에 붙여넣고 **연결 테스트**를 누릅니다.
"연결됨"이 뜨면 준비가 끝났습니다.

> 토큰은 이 브라우저에만 저장됩니다. **공용 컴퓨터에서는 사용하지 마세요.**
> 유출된 것 같으면 [토큰 목록](https://github.com/settings/tokens)에서 즉시 삭제(Revoke)할 수 있습니다.

## 매달 하는 일

1. **새 편지 쓰기** → 제목과 본문을 씁니다. 쓰는 동안 자동으로 임시저장됩니다.
2. **사진 추가** → 구글 드라이브 공유 링크를 붙여넣습니다. 바로 미리보기로 확인됩니다.
3. **발행** → 버튼 한 번이면 저장소에 올라가고 공유 링크가 나옵니다.
4. 후원자에게 **링크와 비밀번호**를 함께 보냅니다.

편지는 언제든 **수정**해서 다시 발행할 수 있습니다. 링크는 그대로입니다.

---

## 사진이 후원자에게 안 보인다면

가장 흔한 문제입니다. 드라이브에서 사진의
**공유 → 일반 액세스 → ‘링크가 있는 모든 사용자’** 로 바꿔 주세요.

> 선교사님은 구글에 로그인되어 있어서 설정이 잘못돼도 화면에는 사진이 보입니다.
> 앱이 발행 전에 확인을 요청하는 이유입니다. 확인하려면 **시크릿 창**으로 편지 링크를 열어 보세요.

---

## 알아 두실 점

- **비밀번호를 잊으면 그 편지는 다시 열 수 없습니다.** 복구 수단이 없습니다. 안전한 곳에 적어 두세요.
- 비밀번호는 8자 이상으로 하세요. 짧거나 숫자만 있으면 추측당할 수 있습니다.
- **사진은 암호화되지 않습니다.** 드라이브에서 공개로 제공되므로, 링크를 아는 사람은 사진을 볼 수 있습니다. 민감한 사진은 올리지 마세요.
- 발행 날짜와 편지 개수는 저장소에서 드러납니다. 편지 내용과 제목은 드러나지 않습니다.
- 발행 후 GitHub Pages 반영에 **최대 1분**이 걸릴 수 있습니다.

## 만드는 사람을 위한 메모

서버 없는 정적 웹앱입니다. 빌드 단계가 없습니다.

```bash
python3 -m http.server 4173
```

`http://localhost:4173` 로 열면 됩니다. 단, 암호화(WebCrypto)는 HTTPS 또는 localhost 에서만 동작합니다.

| 파일 | 역할 |
|---|---|
| `assets/js/crypto.js` | PBKDF2 + AES-GCM 암·복호화 |
| `assets/js/github.js` | Contents API — 발행 |
| `assets/js/drive.js` | 드라이브 링크 파싱·검증 |
| `assets/js/letters.js` | 편지 데이터 계층 |
| `assets/js/render.js` | 편지 렌더링·인쇄 (보기/미리보기 공용) |
| `assets/js/views/` | 화면 4개 |
